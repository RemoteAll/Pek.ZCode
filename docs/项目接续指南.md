## 1. 项目速览

- 名称：`Pek.ZCode`；目录 `G:\Code\Zig\Pek.ZCode`。
- 定位：**DH.NCode（XCode ORM）的 Zig 实现**——语义与逻辑对齐 C# `G:\Code\Pek.FrameWork\DH.NCode`
  与 Rust `G:\Code\Rust\Pek.RCode`，共用同一份 `Model.xml`、同一个数据库。
  逐项对照（含未实现清单与行为差异）见 `docs/移植对照-NCode.md`．
- 工具链：Zig **0.17.1**（VS Code Zig 扩展托管，`zig version` 实测 0.17.1；0.17.x 均可，0.17.0 已验证同行为）；
  依赖公共库 `G:\Code\Zig\zzig`（path 依赖）：`zzig.xml`（XML DOM）+ 通用件 `zzig.Decimal` / `zzig.DateTime`
  / `zzig.db.Value` / `zzig.db.Row` / `zzig.db.sqlite` / `zzig.db.mysql` / `zzig.crypto.rsa` / `zzig.Buf` / `zzig.File`。
  **本仓不再保留这些通用件的副本**（同一能力只允许一份实现）。
- 当前范围：`Model.xml` 解析、类型/值、5 族方言的 SQL 与 DDL、`Where`/分页、**SQLite + MySQL 执行驱动**、
  表级 CRUD、对象实体与脏更新、批量写、整表缓存与单对象缓存、事务、连接串与增量结构同步（`Full` 删列删索引）、
  **分表分库 / 读写分离 / 连接池 / 写入拦截器 / 延迟写队列 / 导航属性 / 树形实体 / 备份**、
  **反向工程（库 → `Model.xml`）**、代码生成。
  **未做**：远程服务（`DbServer`）、SQL Server/PostgreSQL/Oracle 执行驱动、MySQL TLS/压缩/LOCAL INFILE、跨连接分片。
- 远端：`https://github.com/RemoteAll/Pek.ZCode`（`origin/main`）。

## 2. 常用命令

```powershell
zig version                                                                                   # 0.17.1
zig build                                                                                     # 编译校验
zig build test                                                                                # 单元 + 集成测试（本仓 99 项）
zig build bench                                                                               # 性能基准（ReleaseFast，打印各组单次耗时；不进门禁）
zig build green-test                                                                          # 绿色版自检（临时库，失败非 0）
zig build codegen -Dmodel=examples/demo-model.xml -Dout=examples/entities                    # 从模型重生实体
# 反向工程：现有库 → Model.xml（--out 是文件路径）
.\zig-out\bin\zcodegen.exe --reverse "Provider=MySQL;Server=127.0.0.1;Port=3307;Database=zcode_test;UserID=root" --out Entity\Model.xml
zig build unit                                                                                # 仅单元测试
zig build integration                                                                         # 仅集成测试
# 改 zzig 后必须连带跑：cd ..\zzig; zig build test（84 项）
# 本地 MySQL 真库（免安装版实例，端口 3307，数据目录 .tools\mysql\data-3307）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\mysql-local.ps1 -Action setup   # 初始化/启动/建库（幂等）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\mysql-local.ps1 -Action status  # 看实例状态
powershell -NoProfile -ExecutionPolicy Bypass -File tools\mysql-local.ps1 -Action stop    # 停止
zig build integration -Dmysql-conn="Provider=MySQL;Server=127.0.0.1;Port=3307;Database=zcode_test;UserID=root;Password="   # 本地真库（tools/mysql-local.ps1 起）

# 一键回归（构建 → 测试；退出码 0/1）
powershell -NoProfile -ExecutionPolicy Bypass -File tools/regression.ps1

# 接续基建
powershell -NoProfile -ExecutionPolicy Bypass -File tools/continuity/install-global-instruction.ps1   # 用户级指令自检（幂等）
powershell -NoProfile -ExecutionPolicy Bypass -File tools/continuity/sync-memory.ps1                  # 本机工作记忆 → docs\项目记忆.md
```

测试现状（2026-11-11）：本仓 **62 项全通过**（单元 48 + 集成 14；其中 MySQL 真库 4 项需 `-Dmysql-conn`，未给时显式 SKIP）；
通用件与驱动（Decimal/DateTime/值模型/Row/SQLite/MySQL/RSA/Buf/File）的测试在 `zzig`：`cd ..\zzig; zig build test` → **84 项全通过**。
回归脚本已把 zzig 一并纳入（`tools/regression.ps1` 末尾会 `cd ..\zzig` 跑一遍）。
