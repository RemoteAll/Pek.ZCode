## 1. 项目速览

- 名称：`Pek.ZCode`；目录 `G:\Code\Zig\Pek.ZCode`。
- 定位：**DH.NCode（XCode ORM）的 Zig 实现**——语义与逻辑对齐 C# `G:\Code\Pek.FrameWork\DH.NCode`
  与 Rust `G:\Code\Rust\Pek.RCode`，共用同一份 `Model.xml`、同一个数据库。
  逐项对照（含未实现清单与行为差异）见 `docs/移植对照-NCode.md`．
- 工具链：Zig **0.17.0**（`zig version` 实测，WinGet 安装）；依赖公共库 `G:\Code\Zig\zzig`（path 依赖）：
  `zzig.xml`（XML DOM）+ 通用件 `zzig.Decimal` / `zzig.DateTime` / `zzig.db.Value` / `zzig.db.sqlite` / `zzig.Buf` / `zzig.File`。
  **本仓不再保留这些通用件的副本**（同一能力只允许一份实现）。
- 当前范围（v0.1.0 第一轮）：`Model.xml` 解析、类型/值、5 族方言的 SQL 与 DDL、`Where`/分页、
  SQLite 执行驱动、表级 CRUD、连接串与增量结构同步。
  **未做**：对象实体/脏更新、缓存、批量写、分表、其它数据库驱动、反向工程、代码生成、备份。
- 远端：**未配置**（`git remote -v` 为空）。

