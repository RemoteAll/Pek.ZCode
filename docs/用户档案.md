## 本项目相关口径

- 中文交流；指令简洁，偏好「直接推进 + 关键处确认」。
- **验证一律走分档**：编译验证用 `zig build`；`dist/` 打包只在用户明确说「打包 / 出包 / 部署」时做（用户已多次强调，不要顺手打包）。
- 每轮收尾必须：决策记录（含原话）+ 记忆同步 + 回归实测输出，缺一不可。
- 复用优先：写码前先检索公共库 → 兄弟项目（`G:\Code\Zig\` 下 `zzig` / `ZZCOM` / `ZZUI` 等）→ 本仓库既有实现，并在交付说明里给检索证据。
