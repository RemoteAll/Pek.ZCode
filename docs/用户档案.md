# 用户档案（Pek.ZCode 定制部分）

> 通用偏好见用户级《跨项目接续协议》（本机 `%APPDATA%\Code\User\prompts\跨项目接续协议.instructions.md`）；本文件只记录**与本项目直接相关**的口径，随首轮开发补全。

## 本项目相关口径

- 中文交流；指令简洁，偏好「直接推进 + 关键处确认」。
- **语义必须对齐参考实现**：以 C# `DH.NCode` 为准、Rust `Pek.RCode` 为已落地范本；
  有差异必须写进 `docs/移植对照-NCode.md`，不允许静默降级。
- **验证一律走分档**：编译验证 `zig build`、测试 `zig build test`；`dist/` 打包只在用户明确说「打包 / 出包 / 部署」时做。
- 每轮收尾必须：决策记录（含原话）+ 记忆同步 + 回归实测输出，缺一不可。
- 复用优先：写码前先检索公共库（`G:\Code\Zig\zzig` 等）→ 兄弟项目 → 本仓库，并给检索证据。

## 已知约束（用户口径）

- 新项目一律 **Zig 0.17.0**；不链 libc（`-lc` 会引 UCRT，Win7 起不来）——SQLite 因此走 **DLL 动态加载**。
- 首选嵌入式 SQLite（与 C# 默认库、Rust 默认链路一致），MySQL 等网络库后续轮次再接。
- 共用 `Model.xml` 是硬约束：C# / Rust / Zig 三端必须能读同一份模型文件。
