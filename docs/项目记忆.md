### Zig 0.17 坑（都在代码里规避了，新增代码别踩回去）
- `std.DynLib` **不支持 Windows** → 手写 `LoadLibraryA`/`GetProcAddress`/`FreeLibrary`。
- 已移除：`time.timestamp`/`nanoTimestamp`、`crypto.random`、`fs.cwd`、`selfExeDirPathAlloc`、`Allocator.dupeZ`。
  替代：`GetSystemTimeAsFileTime` / `GetTickCount64` / `GetModuleFileNameA` / 手工补 `\0`。
- `ArenaAllocator` **不能中途复制**（后续分配只更新副本 buffer_list → 泄漏）；先分配完再整体移入返回值。
- `sqlite3_bind_text` 必须 `SQLITE_TRANSIENT`；`SQLITE_STATIC` + 栈缓冲会在 step 时读到失效内存。
- 连接串 `Data Source` 必须复制：`Dal` 生命周期长于调用方临时串。

### 语义要点
- `Nullable` 缺省 false（NOT NULL）；`TableName` 缺省 = `Name`；视图 = `IsView` 或表名以 `#` 开头。
- SQLite：自增列内联 `PRIMARY KEY AUTOINCREMENT`、`String` 列 `COLLATE NOCASE`、`decimal` 为 NUMERIC 亲和度
  （尾随零入库即丢，C# 同样）；`INSERT/UPDATE/DELETE` 未知列报 `error.ColumnNotFound`。
- `Where` IN 空集 → `1 = 0`，NOT IN 空集 → `1 = 1`；分页/取前 N 无显式排序时按主键兜底。
